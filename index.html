03 / THE N.O.V.A SYSTEM

the visible layer.

Six focused systems work together behind one interface. Each layer has a clear responsibility, so N.O.V.A can grow without turning into one fragile block of code.

01 / ORCHESTRATIONCORE

The brain decides what happens next.

The FastAPI core classifies intent, builds context, enforces memory rules, selects a route, and returns both the answer and the interface state.

  • Prompt builder

02 / CONTINUITYLIVE

Memory with boundaries.

Recent conversation, confirmed long-term facts, and human-readable Obsidian notes remain separate instead of becoming one uncontrolled context dump.

  • SQLite history
  • Confirmed memory
  • NOVA Brain
03 / VOICELIVE

A presence, not a text box.

Wake-word activation, speech recognition, Kokoro voice, and echo protection create a hands-free interaction loop.

  • “NOVA” wake word
  • Local speech output
  • Self-audio guard
04 / ACTIONLIVE

Direct tools for exact work.

Calculations, system status, time utilities, browser actions, and desktop navigation bypass generative reasoning when it is unnecessary.

  • Deterministic routes
  • Lower latency
  • Predictable output
05 / KNOWLEDGEEVOLVING

  • Project search now
  • Semantic search next

CURRENT MVP BOUNDARIES

Credibility means showing the edges.

N.O.V.A v1 is a functioning personal project, not a finished commercial product. The showcase separates verified capability from the approved roadmap.

  1. 01Timers and reminders currently require the backend to remain running.
  2. 02Weather and web actions require an internet connection.
  3. 03Speech recognition can occasionally mishear a command.
  4. 04Web search opens results; live page summarization is planned.
  5. 05Application launching uses a configured supported-app list.
  6. 06The current interface runs in a browser before desktop packaging.
